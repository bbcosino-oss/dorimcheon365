# 🌿 도림천 365 — AI 생태·산책 관찰일지

> 매일 도림천을 걸으며 사진으로 자연과 도시의 변화를 관찰하고, AI로 탐지한 대상을 표·차트·CSV로 기록하는 Streamlit 앱입니다.

## 1. 만든 이유

매일 같은 길을 걷더라도 계절의 색, 새의 모습, 산책하는 사람들의 풍경은 달라집니다. 이 변화들을 사진과 짧은 기록으로 남기고, AI가 찾은 객체를 날짜별 데이터로 쌓아보고자 만들었습니다. 향후 365일 생태 인문 에세이와 도시 관찰 아카이브를 목표로 합니다.

## 2. 사용 모델 및 라이브러리

- **YOLO11 nano (`yolo11n.pt`)**: 일반 객체 탐지 (Ultralytics COCO 사전 학습 모델)
- **Streamlit**: 웹 UI 및 배포
- **Pandas**: 객체별 집계, 날짜별 비교, CSV 출력
- **Pillow**: 이미지 회전 보정, 탐지 상자 그리기

> 일반 YOLO는 백로·왜가리·청둥오리 종을 식별하지 않습니다. COCO의 `bird` 클래스로 분류합니다. '탐지 수'는 실제 생물 개체수와 다를 수 있습니다. 수질 등 환경 지표를 분석하는 앱도 아닙니다.

## 3. 주요 기능

1. 날짜·구간·날씨·계절·생태·산책 메모 작성
2. JPG/PNG 사진 여러 장 업로드
3. AI로 사람·새·자전거·차량 등 객체 탐지 및 시각화
4. 카테고리별 집계, 표, 막대그래프
5. 기존 CSV를 불러와 날짜별 기록 추가 및 누적 추이 표시
6. 분석 사진 PNG·관찰일지 CSV 다운로드
7. 사진들에서 사람이 설정 기준 이상 탐지되면 알림 표시 (중복 탐지 주의)

## 4. 실행 방법

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

최초 실행 시 YOLO 모델 파일 다운로드를 위해 인터넷 연결이 필요합니다. 메모리와 CPU에 따라 추론 속도가 다릅니다.

## 5. Streamlit Community Cloud 배포

1. GitHub에 새 공개 저장소 `dorimcheon365`를 만듭니다.
2. `app.py`, `requirements.txt`, `README.md`, `.gitignore`, `.streamlit/config.toml`을 업로드합니다.
3. https://share.streamlit.io/ 에 GitHub 계정으로 로그인합니다.
4. **Create app** → 저장소 선택 → Branch `main` → Main file path `app.py` → Deploy.
5. 배포 링크를 휴대폰에서도 열어 사진으로 확인합니다.

`demo_images/`의 실제 사진은 GitHub 공개 저장소에 올리지 않도록 `.gitignore`에서 제외했습니다. 실습 화면에서 직접 업로드하십시오.

## 7. 어려웠던 점과 해결 방법

- **새 종 구별 문제:** 일반 객체 탐지 모델은 종 단위 분류가 불가능 → `bird` 탐지 결과와 사람이 직접 적는 생태 메모를 분리함
- **날짜별 기록 유지 문제:** Streamlit Cloud는 파일을 영구 저장하는 데이터베이스가 아님 → CSV 다운로드와 이전 CSV 불러오기 기능으로 해결
- **대용량 사진 문제:** 스마트폰 사진을 1280픽셀 이내로 축소해 CPU 추론 부담을 줄임
- **사진별 중복 문제:** 동일 개체가 여러 사진에 잡힐 수 있음 → 개체수 대신 '사진별 탐지 합계'로 표시함
